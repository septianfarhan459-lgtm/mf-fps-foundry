A round-based, Counter-Strike-style tactical FPS built with three.js 0.187.0: two teams of bots on an
original industrial map ("FOUNDRY"), rounds won by eliminating the enemy team, a buy menu between
rounds, rifle/SMG/DMR with recoil and spread, grenades, take-cover bot AI, minimap radar, gamepad
support and procedural audio. Plays offline from static ES modules in any WebGL2 browser.

## Run

Any static server pointed at `game/`, e.g.:

    node serve.ts --port 8080

then open http://localhost:8080. WASD + mouse, Ctrl crouch, B buy menu, G grenade, Tab scoreboard.
